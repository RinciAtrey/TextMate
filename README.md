# TextMate — AI-powered reply generator (Chrome Extension)

**TextMate** is a Chrome extension that adds an **AI Reply** button to **Gmail, Slack, and LinkedIn Messaging**.  
It extracts the latest message from the conversation and generates a professional AI response, and automatically inserts it into the message composer.


## ✨ Features

- Chrome extension with site-specific content scripts  
- Works on:
  - Gmail
  - Slack
  - LinkedIn Messaging
- One-click **AI Reply** generation
- Automatically inserts generated reply into the composer
- Clean UI placement that matches native platform controls
- React based frontend website




## ❔How to use the Extension:

- Open Chrome → chrome://extensions
- Enable Developer Mode
- Click Load unpacked
- Select the extension/ folder
- Open Gmail / Slack / LinkedIn and refresh
